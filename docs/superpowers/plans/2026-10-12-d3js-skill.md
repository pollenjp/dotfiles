# pjp-d3js skill を足し、図の skill を並べて案内している箇所にも添える Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pjp-drawio / pjp-plantuml と同じ形の D3.js 用 skill `pjp-d3js` を dotfiles に足し (chart module `d3js/*.mjs` を `d3js-export.sh` で SVG・PNG に書き出す・`d3js-vendor.sh` で cc-pages の対話ページに d3.min.js を写す)、2 つを並べて案内している 9 ファイル (claude-skills 7・dotfiles 2) に pjp-d3js を同列で足す。

**Architecture:** skill の `flake.nix` が `package-lock.json` から `importNpmLock.buildNodeModules` で node_modules (d3・Observable Plot・linkedom) を store に作り、devShell が `PJP_D3JS_NODE_MODULES` と `PJP_D3JS_FONTS_DIR` を渡す。`scripts/lib/render.mjs` はファイルごとに linkedom の window / document を global に置き、`node:module` の `registerHooks` で「ふつうの解決で見つからないパッケージ名を skill の node_modules から探し直す」fallback を足してから chart module を import し、返った SVG 要素に xmlns と白背景を足して書く。PNG は resvg に flake の Noto Sans CJK を渡して作る。

**Tech Stack:** Node 24 (nixpkgs の `nodejs`)・d3 7.9.0・@observablehq/plot 0.6.17・linkedom 0.18.13・resvg・noto-fonts-cjk-sans、bash (`set -eu -o pipefail`・shfmt・shellcheck)、Nix flake (`importNpmLock`・`lib.fileset`)、GitHub Actions。

- [ ] **Step 4: `flake.nix` を書く**

`nix/files/claude/skills/pjp-d3js/flake.nix`:

```nix
{
  description = "pjp-d3js skill の依存 (node + d3・Observable Plot・linkedom + resvg + 日本語フォント)";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixpkgs-unstable";
  };

  # この skill は store へコピーされる (read-only) ので、flake.lock は必ず
  # 一緒に commit する。lock が無いと nix がその場で書こうとして失敗する。
  outputs =
    { nixpkgs, ... }:
    let
      inherit (nixpkgs) lib;

      # dotfiles/nix/flake.nix と同じ範囲。
      systems = [
        "x86_64-linux"
        "aarch64-linux"
        "aarch64-darwin"
      ];
      forAllSystems = lib.genAttrs systems;

      packagesFor = pkgs: rec {
        default = node-modules;

        # d3・Observable Plot・linkedom の node_modules。
        #
        # package-lock.json の integrity で 1 つずつ取るので npmDepsHash を持たない。
        # 版を上げるときは lock を作り直すだけでよい (SKILL.md の「版」)。
        #
        # skill のディレクトリは store へコピーされて読み取り専用になるので、
        # node_modules を skill の中に作ることはできない。scripts/lib/render.mjs が
        # PJP_D3JS_NODE_MODULES (下の devShell が渡す) からここを読む。
        node-modules = pkgs.importNpmLock.buildNodeModules {
          # package.json と package-lock.json だけを渡す。skill のディレクトリごと
          # 渡すと、SKILL.md を直しただけで作り直しになる。
          npmRoot = lib.fileset.toSource {
            root = ./.;
            fileset = lib.fileset.unions [
              ./package.json
              ./package-lock.json
            ];
          };
          inherit (pkgs) nodejs;
        };
      };
    in
    {
      packages = forAllSystems (system: packagesFor nixpkgs.legacyPackages.${system});

      # scripts/*.sh は、PJP_D3JS_NODE_MODULES が無ければここへ入り直す。
      devShells = forAllSystems (
        system:
        let
          pkgs = nixpkgs.legacyPackages.${system};
          tools = packagesFor pkgs;
        in
        {
          default = pkgs.mkShellNoCC {
            packages = [
              pkgs.nodejs
              # SVG -> PNG (目で確かめる用)。Chromium を起こすより軽い。
              pkgs.resvg
            ];

            # chart module の "d3" などを解決する先 (scripts/lib/render.mjs)。
            PJP_D3JS_NODE_MODULES = "${tools.node-modules}/node_modules";

            # resvg に渡す日本語フォント。resvg は fontconfig を読まないので、
            # ディレクトリを --use-fonts-dir で直に渡す。可変フォント
            # (NotoSansCJK-VF) のままで太字も描ける (2026-10-12 に確かめた)。
            PJP_D3JS_FONTS_DIR = "${pkgs.noto-fonts-cjk-sans}/share/fonts";
          };
        }
      );

      formatter = forAllSystems (system: nixpkgs.legacyPackages.${system}.nixfmt);
    };
}
```

```js
// 原点を中心にした viewBox の力学グラフ。白背景が viewBox の左上から敷かれるか、
// .stop() して tick を手で回すと毎回同じ形になるかを見る。
import * as d3 from "d3";

export default function () {
  const w = 400;
  const h = 240;
  const nodes = d3.range(12).map((i) => ({ id: i }));
  const links = d3.range(1, 12).map((i) => ({ source: Math.floor((i - 1) / 2), target: i }));
  const sim = d3
    .forceSimulation(nodes)
    .force(
      "link",
      d3
        .forceLink(links)
        .id((d) => d.id)
        .distance(30),
    )
    .force("charge", d3.forceManyBody().strength(-60))
    .force("x", d3.forceX())
    .force("y", d3.forceY())
    .stop();
  for (let i = 0; i < 300; ++i) sim.tick();

  const svg = d3
    .create("svg")
    .attr("width", w)
    .attr("height", h)
    .attr("viewBox", [-w / 2, -h / 2, w, h]);
```

```js
// chart module (*.mjs) を読み込み、返った SVG 要素を <out-dir>/<名前>.svg に書く。
//
// d3js-export.sh から呼ぶ。PJP_D3JS_NODE_MODULES は devShell (flake.nix) が渡す。
//
//   node render.mjs --out-dir <dir> [--transparent] -- <file.mjs>...
//
// ## なぜ要るか
//
// Node には DOM が無いので、D3 も Plot もそのままでは要素を作れない。ファイルごとに
// linkedom の window と document を作って global に置き、ブラウザ向けの書き方
// (d3.create("svg")・Plot.plot({...})) のまま動かす。
//
// chart module はプロジェクトの d3js/ に置くので、そこから "d3" を import しても
// node_modules が見つからない。skill の node_modules は store にあり、skill の中に
// 置くこともできない (skill 自体が store へコピーされ読み取り専用になる)。そこで
// resolve hook を足し、ふつうの解決で見つからないパッケージ名だけを skill の
// node_modules から探し直す。プロジェクトが自前の d3 を持っていればそちらが先に使われる。

import { mkdirSync, writeFileSync } from "node:fs";
import { registerHooks } from "node:module";
import { basename, resolve } from "node:path";
import { pathToFileURL } from "node:url";
import { parseArgs } from "node:util";

const SVG_NS = "http://www.w3.org/2000/svg";

function die(message) {
  console.error(message);
  process.exit(1);
}

const nodeModules = process.env.PJP_D3JS_NODE_MODULES;
if (!nodeModules) die("PJP_D3JS_NODE_MODULES がありません。d3js-export.sh から呼んでください");

// 探し直すときの呼び出し元。node_modules の親ディレクトリにあるファイルに見立てると、
// Node はそこから node_modules/<パッケージ名> を探す。
const fallbackParent = pathToFileURL(`${resolve(nodeModules, "..")}/`).href;

// "./x" "../x" "/x" や "node:fs" "file:///x" のような URL ではないもの = パッケージ名
const isPackageName = (specifier) => !/^(\.{0,2}\/|[a-zA-Z][a-zA-Z0-9+.-]*:)/.test(specifier);

registerHooks({
  resolve(specifier, context, nextResolve) {
    try {
      return nextResolve(specifier, context);
    } catch (err) {
      if (err?.code !== "ERR_MODULE_NOT_FOUND" || !isPackageName(specifier)) throw err;
      try {
        return nextResolve(specifier, { ...context, parentURL: fallbackParent });
      } catch (err2) {
        if (err2?.code === "ERR_MODULE_NOT_FOUND") {
          err2.message += "\n(skill の node_modules にあるのは d3・@observablehq/plot・linkedom とその依存だけ)";
        }
        throw err2;
      }
    }
  },
});

const { values, positionals } = parseArgs({
  allowPositionals: true,
  options: {
    "out-dir": { type: "string", default: "out" },
    transparent: { type: "boolean", default: false },
  },
});
if (positionals.length === 0) die("chart module (*.mjs) を渡してください");

// hook を足したあとで読む (linkedom も skill の node_modules にある)。
const { parseHTML } = await import("linkedom");

function toSvgElement(node) {
  if (node == null) {
    throw new Error("default export の関数が何も返していません (最後に return svg.node(); と書く)");
  }
  // d3 の selection を返したときは中の要素を取り出す
  if (typeof node.node === "function") node = node.node();
  const tag = String(node.tagName ?? "").toLowerCase();
  if (tag === "figure") {
    throw new Error(
      "SVG ではなく <figure> が返りました。Plot は title・subtitle・caption や legend を付けると " +
        "figure (HTML) を返します。題は図の外に書き、凡例はマークで描いてください (references/troubleshooting.md)",
    );
  }
  if (tag !== "svg") throw new Error(`SVG 要素ではなく ${tag ? `<${tag}>` : typeof node} が返りました`);
  if (!node.getAttribute("xmlns")) node.setAttribute("xmlns", SVG_NS);
  return node;
}

// 白背景を先頭に敷く。viewBox が 0,0 から始まるとは限らない (力学グラフは原点を
// 中心にしがち) ので、viewBox があればその範囲、無ければ width / height を覆う。
function addWhiteBackground(svg, document) {
  const rect = document.createElementNS(SVG_NS, "rect");
  const box = (svg.getAttribute("viewBox") ?? "").trim().split(/[\s,]+/).map(Number);
  if (box.length === 4 && box.every(Number.isFinite)) {
    const [x, y, width, height] = box;
    rect.setAttribute("x", String(x));
    rect.setAttribute("y", String(y));
    rect.setAttribute("width", String(width));
    rect.setAttribute("height", String(height));
  } else {
    rect.setAttribute("width", svg.getAttribute("width") ?? "100%");
    rect.setAttribute("height", svg.getAttribute("height") ?? "100%");
  }
  rect.setAttribute("fill", "#ffffff");
  svg.insertBefore(rect, svg.firstChild);
}

async function renderOne(file) {
  // ファイルごとに document を作り直す。前の図が body に足した要素を持ち越さない。
  const { window, document } = parseHTML("<!doctype html><html><head></head><body></body></html>");
  globalThis.window = window;
  globalThis.document = document;

  const mod = await import(pathToFileURL(resolve(file)).href);
  if (typeof mod.default !== "function") {
    throw new Error("default export が関数ではありません (export default function () { …; return svg.node(); })");
  }
  const svg = toSvgElement(await mod.default({ document }));
  if (!values.transparent) addWhiteBackground(svg, document);

  writeFileSync(resolve(values["out-dir"], `${basename(file, ".mjs")}.svg`), `${svg.outerHTML}\n`);
}

mkdirSync(values["out-dir"], { recursive: true });

// 1 つ失敗しても残りは書き出し、最後にまとめて失敗を返す (直す箇所を 1 回で全部見せる)。
let failed = 0;
for (const file of positionals) {
  try {
    await renderOne(file);
  } catch (err) {
    failed += 1;
    console.error(`✗ ${file}`);
    console.error(err?.stack ?? String(err));
  }
}
if (failed > 0) die(`${failed} 件の chart module が失敗しました`);
```

```bash
  curl -fsSL https://install.determinate.systems/nix | sh -s -- install"

formats=svg
out_dir=out
scale=1
transparent=0
inputs=()

need_value() {
  [[ $# -ge 2 ]] || die "$1 に値がありません"

while [[ $# -gt 0 ]]; do
  case $1 in

      die "知らないオプション: $1 (--help を見る)"
      ;;
    *)
      inputs+=("$1")
      shift
      ;;
  esac
done

  case ${fmt} in
    svg) want_svg=1 ;;
    png) want_png=1 ;;
    '') ;;
    *) die "知らない形式: ${fmt} (svg / png)" ;;
  esac
done

[[ ${scale} =~ ^[0-9]+([.][0-9]+)?$ ]] || die "拡大率は正の数で: ${scale}"

    # _ で始まるものは部品 (色・軸の共通化など)。書き出さない
    [[ $(basename "${f}") == _* ]] || inputs+=("${f}")
  done
  shopt -u nullglob
fi

[[ ${#inputs[@]} -gt 0 ]] || die "対象の .mjs がありません ($(pwd))"

seen=$'\n'
for input in "${inputs[@]}"; do
  [[ -f ${input} ]] || die "ファイルがありません: ${input}"
  [[ ${input} == *.mjs ]] || die ".mjs ではありません: ${input}"
  base=$(basename "${input}")
  base=${base%.mjs}
  case ${seen} in
    *$'\n'"${base}"$'\n'*) die "出力の名前がぶつかります: ${base} (${input})" ;;
  esac
  seen+="${base}"$'\n'
done

##########
# 変換   #
##########

tmp_dir=$(mktemp -d)
trap 'rm -rf "${tmp_dir}"' EXIT

# PNG だけ欲しいときは、SVG を一時ディレクトリに書いてから変換する。
svg_dir=${out_dir}
if ((!want_svg)); then
  svg_dir=${tmp_dir}
fi

# 作り直すものだけ先に消す。失敗した chart module の古い出力を、新しいものと取り違えない。
for input in "${inputs[@]}"; do
  base=$(basename "${input}")
  base=${base%.mjs}
  if ((want_svg)); then
    rm -f "${out_dir}/${base}.svg"
  fi
  if ((want_png)); then
    rm -f "${out_dir}/${base}.png"
  fi
done

render_args=(--out-dir "${svg_dir}")
if ((transparent)); then
  render_args+=(--transparent)
fi

# (render.mjs は失敗の理由を出して 1 で終わる)。
render_status=0
node "${skill_dir}/scripts/lib/render.mjs" "${render_args[@]}" -- "${inputs[@]}" || render_status=$?

# resvg の無害な警告。Plot の <style> にある :where() を読めない、など。
resvg_noise='is not supported\. Selector skipped'

count=0
for input in "${inputs[@]}"; do
  base=$(basename "${input}")
  base=${base%.mjs}
  svg="${svg_dir}/${base}.svg"
  # 無ければ render.mjs が失敗の理由を出している
  [[ -f ${svg} ]] || continue

  if ((want_svg)); then
    echo "==> ${out_dir}/${base}.svg"
    count=$((count + 1))
  fi

  if ((want_png)); then
    png="${out_dir}/${base}.png"
    echo "==> ${png}"
    # resvg は fontconfig を読まないので、flake のフォントのディレクトリを直に渡す。
    # font-family が無い・知らない名前 (system-ui など) のときも日本語が出るよう、
    # 既定と sans-serif を Noto Sans CJK JP にする。
    if ! resvg --use-fonts-dir "${PJP_D3JS_FONTS_DIR}" \
      --font-family "Noto Sans CJK JP" \
      --sans-serif-family "Noto Sans CJK JP" \
      --zoom "${scale}" \
      "${svg}" "${png}" 2>"${tmp_dir}/resvg.log"; then
      cat "${tmp_dir}/resvg.log" >&2
      die "resvg が失敗しました: ${svg}"
    fi
    grep -vE "${resvg_noise}" "${tmp_dir}/resvg.log" >&2 || true
    [[ -f ${png} ]] || die "出力が作られませんでした: ${png}"
    count=$((count + 1))
  fi
done

((render_status == 0)) || die "失敗した chart module があります (理由は上)"
echo "${count} 件を ${out_dir}/ へ出力しました"
```

```bash
#!/usr/bin/env bash
# shellcheck shell=bash
#
# d3.min.js (と plot.umd.min.js) を指定のディレクトリへ写す。cc-pages の standalone
# ページのように、CDN を読めないページで D3 / Observable Plot を動かすときに使う。
#
# ## なぜ写すのか
#
# cc-pages のページの CSP は script-src 'self' 'unsafe-inline' で、外部のオリジン
# (CDN) は止まる。ページの assets/ に置けば 'self' として読める。
#
# store を指す symlink にはしない。GC で store から消えてもページが動き続けるように、
# 中身を複製する。store のファイルは読み取り専用なので、書き込めるモードで置く
# (cp のままだと、次に写し直すときに上書きできない)。
#
# ## 依存
#
# d3 と Plot は、この skill の flake.nix が作る node_modules にある。
# devShell が渡す PJP_D3JS_NODE_MODULES が無ければ、自動で devShell へ入り直す。

set -eu -o pipefail

skill_dir=$(
  cd -- "$(dirname -- "$(readlink -f -- "$0")")/.." &>/dev/null
  pwd -P
)

have() {
  command -v "$1" &>/dev/null
}

die() {
  echo "$*" >&2
  exit 1
}

usage() {
  cat <<'EOS'
usage: d3js-vendor.sh [--plot] DIR

DIR (例: cc-pages のページの assets/) に d3.min.js を写す。DIR が無ければ作る。

options:
  --plot       plot.umd.min.js も写す (ページでは d3.min.js の後に読む)
  -h, --help   これ

例:
  d3js-vendor.sh "$dir/assets"          # dir は cc-pages new が返したもの
  d3js-vendor.sh --plot "$dir/assets"
EOS
}

for arg in "$@"; do
  case ${arg} in
    -h | --help)
      usage
      exit 0
      ;;
  esac
done

# 印を付けて 1 回だけにする (devShell に入っても揃わない場合の無限ループ防止)。
if [[ -z ${PJP_D3JS_NODE_MODULES:-} ]] || ! have node; then
  if [[ -z ${D3JS_SKILL_REEXEC:-} ]] && have nix; then
    export D3JS_SKILL_REEXEC=1
    exec nix develop "path:${skill_dir}" --command "$0" "$@"
  fi
  die "d3 の node_modules が見つかりません (PJP_D3JS_NODE_MODULES が空)。
nix があれば devShell へ自動で入り直します。"
fi

plot=0
dest=
while [[ $# -gt 0 ]]; do
  case $1 in
    --plot)
      plot=1
      shift
      ;;
    -*)
      die "知らないオプション: $1 (--help を見る)"
      ;;
    *)
      [[ -z ${dest} ]] || die "DIR は 1 つだけ: ${dest} と $1"
      dest=$1
      shift
      ;;
  esac
done
[[ -n ${dest} ]] || die "写す先の DIR を渡してください (--help を見る)"

nm=${PJP_D3JS_NODE_MODULES}

# 写したものの版 (package.json の version)
version_of() {
  node -p 'require(process.argv[1]).version' "${nm}/$1/package.json"
}

copy() {
  local src=$1 name=$2 pkg=$3
  [[ -f ${src} ]] || die "見つかりません: ${src}"
  install -m 0644 "${src}" "${dest}/${name}"
  echo "==> ${dest}/${name} (${pkg} $(version_of "${pkg}"))"
}

mkdir -p "${dest}"
copy "${nm}/d3/dist/d3.min.js" d3.min.js d3
if ((plot)); then
  copy "${nm}/@observablehq/plot/dist/plot.umd.min.js" plot.umd.min.js @observablehq/plot
fi

dir_name=$(basename "${dest}")
echo
echo "ページ (index.html) からは相対パスで、この順に読む:"
echo "  <script src=\"${dir_name}/d3.min.js\"></script>"
if ((plot)); then
  echo "  <script src=\"${dir_name}/plot.umd.min.js\"></script>"
fi
```

````markdown
## D3 か Plot か

| 描きたいもの | 書くもの |
| --- | --- |
| 棒・折れ線・面・散布・ヒートマップ・箱ひげなど、定番の形 | Observable Plot（数行で済む） |
| 力学グラフ・treemap・sunburst・地図・等高線・独自の形 | D3 |
| ズーム・ドラッグ・ブラシ・遷移で触って操作したい | D3 の対話ページ（下の「対話ページ」） |
| 関係・流れ・構成（箱と線） | `pjp-plantuml` / `pjp-drawio` |

Plot は D3 と同じチームの上位の層で、中で D3 を使っている。迷ったら Plot で書き始め、
Plot の mark で表せないところだけ D3 に降りる。

## chart module の書き方

default export の関数が **SVG 要素を返す**（async でもよい）。D3 の公式の例と同じく
`import * as d3 from "d3"` と書ける（skill の node_modules から読まれる）。使える npm パッケージは
`d3`・`@observablehq/plot`・`linkedom` と、その依存（`d3-time-format` など）だけ。

### D3

```js
// d3js/01_downloads.mjs
import * as d3 from "d3";
import data from "./data/downloads.json" with { type: "json" };

export default function () {
  const width = 640;
  const height = 320;
  const m = { top: 16, right: 16, bottom: 28, left: 52 };
  const x = d3.scaleUtc(d3.extent(data, (d) => new Date(d.month)), [m.left, width - m.right]);
  const y = d3.scaleLinear([0, d3.max(data, (d) => d.count)], [height - m.bottom, m.top]).nice();

  const svg = d3.create("svg").attr("width", width).attr("height", height).attr("viewBox", [0, 0, width, height]);
  svg.append("g").attr("transform", `translate(0,${height - m.bottom})`).call(d3.axisBottom(x));
  svg.append("g").attr("transform", `translate(${m.left},0)`).call(d3.axisLeft(y));
  svg
    .append("path")
    .datum(data)
    .attr("fill", "none")
    .attr("stroke", "#2a78d6")
    .attr("stroke-width", 2)
    .attr("d", d3.line((d) => x(new Date(d.month)), (d) => y(d.count)));
  return svg.node();
}

## 規約

- **白背景。** script が viewBox に合わせて白い矩形を敷く。図の中に背景の矩形を置かない。
  透過が要るときだけ `--transparent`
- **毎回同じ SVG にする。** 乱数は `Math.random` ではなく `d3.randomLcg(42)` を種にする。
  力学グラフは `.stop()` して `tick()` を手で回す（`references/troubleshooting.md`）
- **width・height と viewBox を両方付ける。** width・height が PNG の大きさになり、viewBox が中身の座標になる
- **文字の幅は測れない。** `getBBox` も `getComputedTextLength` も使えない（DOM はあるがレイアウトの
  計算が無い）。余白は文字数から見積もる（troubleshooting）
- **Plot に title・subtitle・caption・legend を付けない。** 付けると SVG ではなく `<figure>`（HTML）が
  返り、script が止まる。題は図の外（Markdown・Notion のキャプション）に書く
- **transition を使わない。** 書き出しは最初の値のまま止まる。最後の値を `attr` で直接入れる
- 色は `dataviz` skill の手順で決める。文字は系列の色で塗らない
- `out/` は生成物。リポジトリに含めるかはプロジェクトの方針に従う
- ファイル名は連番プレフィックス（`01_`, `02_`）で並び順を固定する

## 日本語

SVG の文字は `<text>` のまま残り、見る側（ブラウザ・Notion）のフォントで描かれる。
`font-family` は D3 の軸の既定（`sans-serif`）や Plot の既定（`system-ui, sans-serif`）のままでよい。

PNG は flake の Noto Sans CJK で描く（**system 側にフォントを入れる必要はない**）。
`sans-serif` と、`font-family` が無いときの既定を Noto Sans CJK JP にしてある。
````

````markdown
## 書き出し（d3js-export.sh）

### `Cannot find package 'xxx'`（ERR_MODULE_NOT_FOUND）

skill の node_modules にあるのは `d3`・`@observablehq/plot`・`linkedom` と、その依存だけ。
それ以外の npm パッケージ（topojson-client・lodash など）は import できない。

- 地図は、TopoJSON を GeoJSON に変換したものを `data/` に置いて読む
- どうしても要るパッケージは、この skill の `package.json` に足す（SKILL.md の「版」）

`node 01_xxx.mjs` のように直接動かしたときも同じエラーになる。chart module は
`d3js-export.sh` から呼ぶ（d3 を skill の node_modules から読む仕組みはそちらにある）。

### `default export が関数ではありません` / `何も返していません`

chart module は `export default function () { …; return svg.node(); }` の形にする。
`d3.select("body").append("svg")` で作ったときも、最後に `svg.node()` を返す。

### `SVG ではなく <figure> が返りました`

Plot は `title`・`subtitle`・`caption` か、`color: { legend: true }` などの凡例を付けると、SVG を
`<figure>`（HTML）で包んで返す。SVG のファイルにはできないので、script はここで止まる。

- 題・説明は図の外（Markdown の本文・Notion のキャプション）に書く
- 凡例は、系列の終わりに直接ラベルを置くか（`dataviz` skill）、`Plot.text` で描く

### 文字の幅を測れない（`getBBox` / `getComputedTextLength`）

linkedom は DOM を持つが、レイアウトの計算をしない。文字の幅や要素の大きさは測れない。
軸の余白やラベルの置き場所は、文字数から見積もる:

```js
// 全角は 1em、半角は 0.6em とみなした幅 (px)
const textWidth = (s, size = 10) =>
  [...String(s)].reduce((w, c) => w + (c.codePointAt(0) > 0xff ? size : size * 0.6), 0);
const left = 8 + d3.max(data, (d) => textWidth(d.name, 10)); // 縦軸のラベルが入る余白
```

### transition の値が入らない

書き出しは chart module が返った時点の SVG を書くので、`transition()` で付けた値は入らず、
最初の値のまま残る。chart module では最後の値を `attr` で直接入れる。transition は対話ページでだけ使う。

### 力学グラフが散らばらない・毎回形が違う・枠の外へ飛ぶ

`forceSimulation` は既定で timer で動くので、そのまま返すと動く前の位置で書き出される。
`.stop()` して `tick()` を手で回す。d3-force は固定の種の乱数を使うので、毎回同じ形になる。

```js
const sim = d3.forceSimulation(nodes)
    .force("link", d3.forceLink(links).id((d) => d.id).distance(40))
    .force("charge", d3.forceManyBody().strength(-80))
    .force("x", d3.forceX())
    .force("y", d3.forceY())
    .force("collide", d3.forceCollide(12))
    .stop();
for (let i = 0; i < 300; ++i) {
  sim.tick();
  for (const n of nodes) { // 枠 (viewBox) の中へ戻す
    n.x = Math.max(-w / 2 + pad, Math.min(w / 2 - pad, n.x));
    n.y = Math.max(-h / 2 + pad, Math.min(h / 2 - pad, n.y));
  }
}
```

- viewBox を原点が中心の `[-w / 2, -h / 2, w, h]` にすると、`forceX()` / `forceY()` の既定（0）と揃う
- ラベルが重なるときは、`forceCollide` の半径にラベルの長さを足す（`(d) => r + d.id.length * 2.5`）
- `Math.random` は毎回変わる。乱数が要るなら `d3.randomNormal.source(d3.randomLcg(42))()` のように種を固定する

### 地図の SVG が大きい

`d3.geoPath(projection).digits(1)` で座標の桁を落とす（TKT-144 では 348 KB → 257 KB）。
国の境界の GeoJSON は細かいほど重いので、縮尺に合った粗さのデータを使う。

### 日付の書式を日本語にする

```js
import ja from "d3-time-format/locale/ja-JP" with { type: "json" };
const locale = d3.timeFormatLocale(ja);
const fmt = locale.utcFormat("%-m月"); // 1月, 2月 …
svg.append("g").call(d3.axisBottom(x).tickFormat(fmt));
```

## PNG（resvg）

### PNG と SVG で見た目が少し違う

PNG は目で確かめる用で、正は SVG（ブラウザ・Notion は SVG を描く）。resvg は CSS の一部を読まない。
Plot の `<style>` にある `:where()` は読み飛ばす（d3js-export.sh がその警告を落としている）。

無いと `sans-serif` に落ち、Noto Sans CJK JP になる。SVG を開く側では、その環境のフォントで描かれる。
````
