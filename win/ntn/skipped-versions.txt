# ここに書いた版は、固定した版より新しくても知らせない。手順は win/README.md の「ntn の新しい版が出たとき」。
#
# 1 行に 1 つ、「版 理由」を空白で区切って書く。版は winget の版 (X.Y.Z) の形で書く。
# # で始まる行と空行は読まない。理由の無い行と、版の形でない行は読めずに落ちる。
# 固定した版以下になった行は消してよい (job が知らせる)。manifest に無いので Windows へは配らない。
#
