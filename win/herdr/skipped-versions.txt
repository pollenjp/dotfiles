# Windows の herdr (winget の Herdr.Herdr.Preview) で、上げずに見送った版 (TKT-156)。
#
# nix/scripts/check-winget-version.sh herdr (GitHub Actions の winget-versions が週 1 回流す) が読み、
# ここに書いた版は、固定した版より新しくても知らせない。手順は win/README.md の「herdr の新しい版が出たとき」。
#
# 1 行に 1 つ、「版 理由」を空白で区切って書く。版は winget の版 (<semver>-preview.<日付>-<hash>) の形で書く。
# winget に無い preview (job が <日付>-<hash> だけを出したもの) は、<日付>-<hash> だけを書く。
# # で始まる行と空行は読まない。理由の無い行と、版の形でない行は読めずに落ちる。
# 固定した版以下になった行は消してよい (job が知らせる)。manifest に無いので Windows へは配らない。
#
# 例:
# 0.9.9-preview.2026-12-01-0123456789ab 設定画面 (prefix+s) で落ちる (TKT-xxx)
